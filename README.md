# DG8002 - Week 3 Activity

Complete five small Python programs by following the `TODO` comments in each file. This repository contains **starter instructions, not completed solutions**.

## Getting started

1. Create your own copy of this repository using the method demonstrated by your instructor (for example, a template repository if enabled).
2. Open your copy in GitHub Desktop and then VS Code.
3. Open each numbered `.py` file, read its scenario and `TODO` comments, and write your code.
4. Run each file independently, e.g. `python f26-activity3-partA.py` (or run in Visual Studio Code).
5. Compare your results with the `CHECK YOUR WORK` comments and test alternative values.
6. Commit and push your completed work to **your own** GitHub repository.

## Expectations

Use variables, arithmetic, clear output, and conditionals where the comments request them. You do **not** need to write functions, import modules, or build a user interface. Do not delete the instructional comments; add your code beneath each TODO.
